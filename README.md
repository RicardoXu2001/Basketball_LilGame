# Streetball Coach / 街头篮球教练

夕阳下的城市街头球场，固定等距的 3D 像素微缩场景，搭配实时比赛与教练工作台。

线上地址：[Streetball Coach](https://ricardoxu2001.github.io/Basketball_LilGame/)

## GitHub Pages 部署与后续更新

仓库 `RicardoXu2001/Basketball_LilGame`，发布源为 `main` 分支的根目录。`index.html` 已包含全部运行资源，`.nojekyll` 使 Pages 直接发布静态文件。

后续修改 `src/` 中的源码，在项目目录运行：

```sh
node --test tests/match.test.cjs
node build.mjs
git add src index.html
git commit -m "Update Streetball Coach"
git push origin main
```

推送后 GitHub Pages 会自动更新；可在仓库的 Actions 中查看发布进度。本地浏览器缓存、旧实验脚本和测试截图不会上传。

## 直接运行

**双击 `index.html` 即可开始。** Three.js、脚本、样式和程序化纹理全部内联，无需联网、安装依赖或使用 CDN。浏览器需支持 WebGL，推荐开启硬件加速。

也可以在当前目录执行：

```sh
node serve.mjs
```

打开 `http://127.0.0.1:8765`。若已有服务运行，直接使用该地址。

## 怎么玩

- 蓝绿色是你的河畔队，橙色是铁街队；金色圆环标记持球人。
- 比赛自动进行。六种进攻战术会改变站位、传球概率、出手倾向和体力消耗。
- 调整四种防守策略、三档节奏及四种进攻重点，观察回合执行与日志反馈。
- 点击球员查看九项能力、体力、得分、助攻、篮板、抢断与犯规。
- 点击「换人」选择场上球员与替补。进行中在回合结束执行，暂停时立即执行。
- 请求暂停可以恢复 9 点体力，并暂停模拟。点击「继续」恢复比赛。
- 支持 1× / 2× / 4×、战术视图、技术统计，以及重新开始。
- 空格暂停 / 继续；Esc 关闭对话框。

四节，每节三分钟；24 秒进攻时限；打平进入一分钟加时。第三节交换半场。比赛结束显示结果，可一键重开。

## 修改与验证

不需要 `npm install`。开发及验证需要 Node.js 18+（验证环境为 24.13.0）。

```sh
node build.mjs
node --test tests/match.test.cjs
node qa/verify.mjs
```

`build.mjs` 将以下源码与本地 Three.js 合并到 `index.html`：

| 文件 | 作用 |
| --- | --- |
| `src/match.js` | 固定时间步比赛引擎、属性、回合、战术、换人、体力及比赛结算 |
| `src/court.js` | Three.js 场景、固定正交镜头、程序化纹理、角色动作和篮球轨迹 |
| `src/coach.js` | 教练台、实时信息、球员详情、操作和对话框 |
| `src/app.css` | 桌面及窄屏布局、交互状态、焦点与减少动效支持 |
| `src/tpl.html` | 单文件页面模板 |

`qa/verification.json` 记录最近一次验证结果；浏览器验证证据位于 `qa/evidence`。权威验证会检查浏览器证据与当前构建的 SHA-256，修改或重新构建后需要重新采集浏览器证据。

原有室内版本的编号源码、patch 辅助脚本和旧截图保留在目录中，但新构建只使用上表列出的三个 JS 文件。

当前实机验证采用本地 HTTP。内置预览器的安全策略禁止 `file://` 导航，因此双击文件路径未在该预览器中实测；构建验证会检查没有外部脚本、样式和图片依赖。

## 原型边界

这是可玩的单场教练原型。比赛采用基于球员能力、体力、战术和简化防守响应的概率模型，球员移动与动作采用程序化表达；尚未实现身体碰撞、完整裁判规则、罚球动作和长期生涯存档。罚球结果直接记入日志。若全队八人均达到六犯，最后可用球员保留上场。长期数值平衡、移动设备性能和其他浏览器兼容性仍需后续验证。

Three.js 使用目录中已有的本地 MIT 许可版本，许可声明保留在 `three.min.js` 和内联构建中。
