# 球员、适配与经营规则 / v2

球员公开展示五项核心能力：投篮 S、终结 F、组织 P、防守 D、运动 A。OVR 按位置自动计算，不能单独编辑。

`OVR = round(wS × S + wF × F + wP × P + wD × D + wA × A)`

| 位置 | 投篮 | 终结 | 组织 | 防守 | 运动 |
| --- | ---: | ---: | ---: | ---: | ---: |
| PG | .15 | .12 | .38 | .15 | .20 |
| SG | .35 | .20 | .20 | .10 | .15 |
| SF | .25 | .25 | .15 | .20 | .15 |
| PF | .15 | .25 | .10 | .30 | .20 |
| C | .05 | .30 | .10 | .35 | .20 |

隐藏模拟能力包括移动速度、传球、控球、意识、耐力、篮板、接球投篮和对抗终结。它们由五项核心、体型、位置与打法推导，并参与移动、消耗、失误、投篮与篮板。前端不公开这些细项数值。

## 双预算

- 全队工资帽：140K / 周。初始八人合同共 114K；最多十人。签约费为半周薪，解约费用为四分之一周薪。
- 首发能力帽：400 点。单人成本为五项核心的简单平均后四舍五入，五人相加。它不使用按位置加权的 OVR，避免通过换位置降低成本。
- 赛前未满五人、能力超标或薪资超标均不能开始。比赛中的主动换人也验证能力预算，包含尚未执行的排队换人。
- 轮换球员合同可重谈一次，降薪 10%，代价是球员熟悉度 -6、球队信任 -2；主力不接受轮换降薪。

## 适配

每种进攻体系拥有五项核心的独立权重，以及匹配打法的加成。五外对低投射球员另有空间惩罚。

- 5-Out：投篮与组织，适合接球射手和空间内线。
- Pick and Roll：组织、终结与运动，适合组织发动机、顺下终结者与中锋。
- Motion：组织、投篮和持续分享，适合组织者与无球射手。
- Fast Break：运动与终结，适合突破终结者及换防锋线。
- Isolation：持球得分、终结与运动，适合单打得分手。
- Inside-Out：终结与防守，适合护筐中锋、篮板蓝领和空间内线。

模拟不读取 OVR 决定胜负。出手成功率综合具体能力、体能、手感、对手防守、传球、空间、球队平均适配和化学反应。实际模拟位置决定三分是否成立，出手位置与球的离手坐标来自同一套移动状态。

示例：低总评接球射手在五外中的适配可以明显超过高总评护筐中锋；中锋在内外结合中会恢复优势。能力帽要求为球星配置合适的低成本角色，而非直接堆满高能力球员。

## 磨合、培养与比赛日

化学反应 = `round(球队信任 × .55 + 首发平均熟悉度 × .45)`。新援熟悉度从 24 开始，每次签约令球队信任下降 5；调整首发会重新计算化学反应。

每个比赛日有两次备战额度：

| 项目 | 成本 | 效果 |
| --- | ---: | --- |
| 战术合练 | 8K | 信任 +7，熟悉度 +8；低熟悉度新援 +14。全队体能 -3 |
| 专项培养 | 6K | 23 岁及以下单项 +2，其他 +1。重新计算 OVR 与能力成本；体能 -5 |
| 恢复训练 | 3K | 全队赛前体能 +18 |

单项培养上限为 96，并受球员潜力总评限制。不能无限训练；提高首发核心能力也可能让能力预算超标。

完成比赛后：胜场收入 46K，负场收入 32K，支付四分之一周薪；共同比赛提高熟悉度和信任，恢复 28 点体能，进入下一比赛日并刷新两次备战额度。结算具有比赛日去重保护。游戏资金最低为零，不实现债务系统。

本机使用 `localStorage` 保存阵容、合同、培养、资金与赛程记录。没有账户和云存档；比赛过程不保存，刷新后回到赛前准备。市场报价固定，不模拟合同年限、经纪人、交易和真实球员。

## 动作与清晰度

模拟以固定 50ms 步长更新带速度、加速度和转向的身体状态。阵型为目标，球员以有限速度赶到目标；近身转向与 0.88m 身体间距约束减少重叠。测试覆盖战术与球权变化的连续移动。

渲染在固定步之间插值，步态由实际移动距离驱动。角色具有膝、肘、手部节点，传接球、投篮、篮板和防守各有程序化姿态。背景立方体按材质合批，观众合并为单个网格，降低高清渲染的绘制开销。

默认画质按 CSS 尺寸与设备 DPR 渲染，DPR 上限 2。纹理保持 NearestFilter，抗锯齿关闭；复古模式才使用 .7 倍内部尺寸。手机固定镜头放大场地并裁掉部分街区背景，保留完整球场和两端篮架。
